# homebrew-tap

Homebrew tap for [Bruno Arueira](https://github.com/brunoarueira)'s projects.

Formulas in this tap are published automatically by
[GoReleaser](https://goreleaser.com) when a new release is tagged in
each project's own repository - nothing here is maintained by hand.

## Usage

```sh
brew install brunoarueira/tap/xlq
```

or, to add the tap explicitly first:

```sh
brew tap brunoarueira/tap
brew install xlq
```

## Available formulas

- [`xlq`](https://github.com/brunoarueira/xlq) - a jq/yq-style
  command-line processor for spreadsheet files (`.xlsx`, `.csv`,
  `.tsv`, `.ods`).
